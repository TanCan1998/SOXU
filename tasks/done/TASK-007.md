# 网络超时有界重试与安全恢复

## 描述

依据 PRD P-05 和维护者要求，网络故障及超时需要自动有界重试；额度不足等 429、鉴权失败和用户中止不得自动重试。当前 policy 为 `automaticApiRetries: 0`，本任务要在不与既有恢复策略矛盾的前提下补齐"有界重试"。

## 范围

- 配置有限重试次数及退避；次数与状态持久化，进程重启不能绕过预算，耗尽后暂停并保留 Worktree 与检查点。
- 对可能已执行的写操作和模型请求先确定结果或从已有工作状态恢复；不得盲目重放可能产生副作用的请求或重复创建 PR。
- 保持模型固定，展示重试状态和次数；明确重试可能产生模型费用。
- 同步更新恢复策略、校验与文档，避免与 `automaticApiRetries: 0` 矛盾。
- 用离线注入覆盖瞬时网络故障、超时恢复、耗尽、重启、取消、429、鉴权及已执行的不确定结果；测试不得产生付费请求。
- 同时覆盖检查修复次数上限与恢复入口不能绕过预算；记录目标平台验证。

## 验收标准

- [ ] 瞬时网络故障与超时按配置次数有界重试，退避与计数写入检查点，重启后预算不重置。
- [ ] 429、鉴权失败、用户中止不自动重试，状态为暂停/阻塞并保留 Worktree。
- [ ] 结果不确定时不重复创建 PR，先查证再决定；不产生重复付费请求。
- [ ] 重试状态与次数可在控制台查看，重试会明确提示可能产生费用。
- [ ] 离线测试覆盖上述路径且不发起真实模型调用；相关文档与 policy 表述一致。
