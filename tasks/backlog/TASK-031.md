# 命令面板：拼音首字母搜索与操作执行

## 描述

⌘K 命令面板。纯前端，读设置项元数据做搜索源。

## 范围

- 新增依赖 pinyin-pro（约 3KB gzip），支持首字母匹配（dk → 打开设置 / 打开终端 / 打开 Git / 打开文件）
- 面板：输入框 + 结果列表 + 底部快捷键提示（↑↓ 选择 / ↵ 执行 / Esc 关闭）
- 模糊匹配 + 命中字符高亮
- 命令注册表与设置项共用一份元数据（不重复维护）
- 键盘全流程可用（不依赖鼠标）

## 验收标准

- [ ] pnpm check 通过，测试全绿
- [ ] 拼音首字母能命中中文命令
- [ ] 全键盘操作可完成一次命令执行
- [ ] 新增测试覆盖拼音匹配
