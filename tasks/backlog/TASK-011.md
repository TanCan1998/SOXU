# 通知系统：右下角 Toast + 声音提醒 + 通知历史

## 描述

用户决策不用 Windows 系统通知（经常不弹），改为应用内右下角弹窗；iOS 端将来才走系统通知。参考 PiDeck v0.9.8 的事件分类与设置结构，但不接系统通知通道。

## 范围

- Toast 组件：右下角堆叠、最多 4 条、spring 入场、常驻模式、悬停暂停倒计时
- useNotifications：三类事件（会话完成 / 出错 / 等待输入），数据来自现有 session 事件流，不新增后端 command
- 全局设置：展示时长 5s/10s/30s/常驻、仅失焦时提醒、通知历史（内存，重启清空）
- 声音提醒：总开关 + 音量 + 三事件独立音效 + 试听，Web Audio 实现，托盘状态下也响
- 通知历史抽屉：顶栏铃铛按钮打开

## 验收标准

- [ ] pnpm check 通过，桌面端测试全绿
- [ ] Toast 可堆叠、可关闭、常驻模式与悬停暂停正常
- [ ] 三类事件分别可开关且持久化
- [ ] 声音能播、音量可调、托盘状态下仍响
- [ ] 通知历史能列出与清空
- [ ] 不调用任何系统通知 API
