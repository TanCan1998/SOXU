# 设置页：外观 / 会话 / 扩展 / 系统 四页

## 描述

V4 设置弹窗需要从单页扩成 4 个 tab，覆盖外观定制、会话行为、扩展管理与系统信息。视觉基准为原型 soxu-prototype 的 settings 弹窗。

## 范围

- 外观：主题 / 强调色 6 色 / 界面字号 / 界面字体 / 代码字体 / 正文宽度
- 会话：发送后滚动 / Enter 发送 / 显示工具调用 / 消息时间戳 / 默认思考强度 / 清空会话
- 系统：自动更新 / 任务完成通知开关 / 关闭最小化托盘 / 检查更新 / 恢复默认布局 / 数据目录 / 关于
- 扩展：扩展开关、技能列表、MCP 服务列表（先用常量占位，数据源属后续切片）
- 设置持久化沿用 apps/desktop/src/settings/ 现有模式

## 验收标准

- [ ] pnpm check 通过，桌面端测试全绿
- [ ] 4 个 tab 切换正常且键盘可达
- [ ] 主题与强调色切换实时生效并持久化
- [ ] 新增测试覆盖设置读写与默认值
