# 自主开发策略

Agent 可以在受限 Issue 范围自主设计、编码、运行测试和修复；Reviewer 独立审查。
Agent 不得自改治理规则，不能代替 Runner 直接完成 push/release；失败有界重试，超预算停止并转 Issue 阻塞。
每轮改进应有可验证价值，禁止无需求自发循环重构。

## 超时与暂停优先

不要以无限超时换取成功率。模型启动、长时间无进展、总执行时间、联网命令和构建分别受时间预算约束。额度/网络故障**立即暂停，不自动重新发送付费提示词**，保留状态供用户一句“继续 SOXU”恢复。详细数值见 `docs/development/timeouts-and-recovery.md`。
