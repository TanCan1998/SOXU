# SOXU UI/UX 已批准基线 · ChatGPT 风格启发

> 项目所有者已批准“参考 GPT”的设计方向。这里指清爽、对话优先、低干扰的通用交互思路，**不复制 ChatGPT/OpenAI 的商标、徽标、代码、特定素材或专有视觉标识**。所有界面使用 SOXU 自有名称与视觉体系。

## 设计原则

- **先对话、后工具**：主页首先呈现清晰的对话编辑区，而不是仪表板堆叠。
- **三块区域**：左侧项目/会话导航，中央对话主区，右侧可折叠任务/运行时检查器。
- **克制视觉**：中性色、宽松行距、简洁的输入卡片；支持明暗主题。
- **渐进复杂度**：多 Agent 控制、Worktree、日志、Token 计量放在专用任务页和检查器内。
- **性能优先**：不得无限向 DOM 增加对话/日志节点；长会话使用虚拟滚动和有界缓存。
- **隐私和准确性**：未接入 Pi 之前，只能展示本地原型内容，不能虚构成功回复、消耗、进度或上线状态。

## 布局基线

| 区域 | 桌面宽度参考 | 内容 |
| --- | --- | --- |
| 导航侧栏 | 约 258px，可折叠 | 新对话、搜索、本地会话、项目、Agent 开发 |
| 对话主区 | 自适应，消息最大宽约 755px | 标题、消息、输入框、发送 |
| 右侧检查器 | 约 297px，可折叠 | Pi RPC 连接、开发模型、任务与校验状态 |

宽度小于 910px 隐藏检查器；进一步缩小时收紧侧栏。后续移动布局不是独立产品目标，只保证窄窗口仍可操作。常用快捷键：`Ctrl/Cmd+K` 新对话，`Ctrl/Cmd+B` 收起/展开侧栏，`Enter` 发送，`Shift+Enter` 换行。

## 当前实现范围 (M0)

`apps/desktop/src/App.vue` 是真实 Vue + TS 页面，不是 PNG；[`soxu-ui-preview.html`](soxu-ui-preview.html) 是不依赖 pnpm 的独立交互预览。侧栏、导航、主题切换、本地预览对话、检查器开关均为有效交互；但会话只保存在页面内存中，刷新后消失；发送不会调用 Pi RPC。项目与 Agent 页当前为明确标识的待实现状态。PiDeck 是**开发监控软件**，不是本 UI 的运行时依赖。

## 下一个里程碑 (M1)

1. 为真实 Pi RPC 编写 Rust/TS 类型化事件桥接，明确取消/关闭语义。
2. 会话从 Pi 的来源增量装载；不能把 Vue 本地演示消息当真实历史。
3. 项目与任务数据分别采用稳定 ID；工作树隔离，详情展示真实检查点。
4. 对话滚动采用虚拟列表，增加无障碍用例、颜色对比度/焦点/键盘回归。
5. Windows Node 26 + Rust + Tauri 实机渲染、低内存与关闭进程树的可复现验证。

## 验收和边界

本轮验收范围只覆盖源代码结构、离线状态逻辑及现有 Node 测试。Vue 编译、真实 Tauri/WebView 显示、Playwright/屏幕阅读器测试、不同 DPI/缩放比例仍需实机验证。UI 参考方向获批，并不代表上述实现已完成验收。
