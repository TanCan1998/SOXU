SOXU Agent界面文案示例 · 未调用模型

建议将 会话持久化、Agent 运行进程与自治任务进度 设计为三个独立层次。它们有联系，但不能使用同一状态字段。

  • Session Catalog：保存稳定 SessionId，按需读取 JSONL，支持断点恢复与分页加载。
  • Runtime Supervisor：最多 2 个并行 Pi Agent，使用 generation 隔离迟到事件，避免跨会话串流。
  • Agent Loop：保留阶段 checkpoint 与 Git Worktree，恢复前核对实际外部副作用。
