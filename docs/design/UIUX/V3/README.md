# SOXU UI/UX V3 — 设计预览

> 本包是设计基准，不是已接入 Pi 的运行产品；所有消息、任务和运行状态仅演示。

## 查看方式

双击 `SOXU-UIUX-V3.html`。支持浅色/深色、临时会话、普通会话草稿、对话内容搜索、快捷跳转、任务和审查切换、上下文菜单。

**正式图标**：打开本包时，如 `assets/soxu-approved-icon.png` 不存在，页面自动显示 *临时备用* S/X 标志。若本机有 SOXU 仓库，在 Windows PowerShell 执行 `./copy-approved-icon.ps1` 自动将仓库 `apps/desktop/src/assets/soxu-256.png` 复制为此文件。脚本只读取仓库资源，不修改项目文件。

## 确认的 V3 变更

- 主内容背景：浅色 `#FCFCFC`，深色 `#191717`
- 强调色：两种主题统一 `#3A83F7`
- 顶栏全局搜索：文本 + 快捷键独立、留白、避免溢出；`Ctrl+K` 打开命令搜索
- 左侧：只保留设置齿轮，不显示 S/账户占位；项目栏改称“项目”，`+` 新建项目
- 会话入口：普通会话、临时会话并列；临时会话不进入历史，允许手动转为普通会话。**此预览所有消息仍仅在页面内存，不提供真正持久化**
- 会话右侧：对话导航、当前已加载消息全文匹配、上下跳转、`Ctrl+F`
- 上下文操作：三点“更多”，不用终端图标
- 标准产品图标：正式实现复用 repo `apps/desktop/src/assets/soxu-256.png`，不得用原型备用图替换。

## 真实 Vue 产品的实现

查阅 `AGENT-IMPLEMENTATION.md`。本项目当前 `App.vue` 是 M0 的本地原型，`UiIcon.vue` 的齿轮是手写 SVG；正式实现建议在现有 `@lucide/vue@1.61.0` 上引用 `Settings` 等标准图标，无需引入新图标库。

## 设计演示与真实行为

- `临时会话`：演示模式只存在 JS 变量中，切换到历史会话即丢失。正式设计建议由 Session Catalog 标记 `ephemeral`，不写 JSONL、不纳入最近历史/全文索引，退出时销毁；如转存则执行显式 Session 持久化及用户可见的成功/失败反馈。
- `普通会话草稿`：演示也不会真正写磁盘。真实产品只有收到 Session Catalog 持久化确认时，才可显示“已保存”。
- `搜索`：演示仅检索当前已加载 DOM。真实实现基于后台分页搜索，跳转稳定消息 ID。
- `Agent/CI/任务`：均为标注的演示状态，不得传递为实际状态。
