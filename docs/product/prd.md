# SOXU 产品需求与验收基线（PRD v0.2 草案）

> 状态：**新产品，尚未启动正式开发**。仓库中的 v1.x ZIP 仅为引导工程与 Agent 调度原型；文档中的指标是拟定的验收标准，不是已测成绩。项目起始版本为 0.1.0；依赖版本、开发模型和 UI/UX 方向已由所有者批准，但锁文件生成与实机验证仍待完成。

## 1. 产品定义

**SOXU / 索序** 是面向 Windows、macOS 和 Linux 的轻量 Pi Agent 桌面工作台，强调多项目、多会话、多 Agent 并行、会话恢复和可观测资源占用；参考 PiDeck 的优秀交互体验，但不复制其代码或将 PiDeck 集成到交付应用中。

- **产品运行时**：Rust（Edition 2024 已批准）+ Tauri 2 稳定版 + Vue 3 + TypeScript + Vite，使用官方 Pi Agent 的 RPC/会话能力。
- **开发基础设施**：Pi Agent 执行自主开发、PiDeck 交互与人工监控、Git Worktree 隔离、GitHub Issues/PR/Actions 验收、AtomGit 加速镜像。
- **最终用户价值**：在一个桌面工作区中高效管理长期 Pi 会话和并行任务，减少空闲资源占用，并能可靠恢复中断状态。

## 2. 用户和典型任务

| 角色 | 关键场景 | 结果 |
| --- | --- | --- |
| 单机开发者 | 切换项目和长期会话 | 不丢上下文、可快速查找历史 |
| 并行开发者 | 2 个及以上独立 Agent 任务 | 互不串扰，可停止/恢复，状态准确 |
| 审查者 | 跟踪工具调用、变更、失败 | 可定位任务和失败原因、留存证据 |
| 资源敏感用户 | Windows 16 GB 开发机长期运行 | 空闲不会无上限累积进程和日志占用 |

## 3. MVP 必做范围（M0–M2）

1. **基础窗口**：原生安装/启动；Tauri ↔ Rust ↔ Vue 的有类型通信；基础错误和关闭流程。
2. **项目管理**：添加/移除工作区引用（不删除磁盘目录）、最近打开项目、目录权限确认。
3. **Pi 集成**：Pi RPC 会话新建、发送、流式消息、停止、恢复；正确识别 `agent_settled`、工具事件、异常退出。
4. **会话管理**：有界 JSONL 索引与增量加载，搜索/切换、滚动定位、历史保留；会话数据格式由 Pi 管理。
5. **并行运行**：至少 2 个独立 Pi Agent 任务，跨工作区不串流、取消具幂等性、切换 UI 不终止任务。
6. **资源与可靠性**：进程树监控，空闲进程释放，关闭时清理受 SOXU 管理的进程，断电/崩溃后可识别并恢复会话。

MVP 暂不包含完整 IDE、远程部署、内嵌浏览器 Agent、云同步、CEF、完整插件市场、移动端和桌宠。

## 4. 可验证验收标准

| 编号 | 指标 | 验收方法 | 门槛 |
| --- | --- | --- | --- |
| P-01 | 同时运行 2 个 Pi 任务 | Windows 16 GB 实机、独立项目/会话 | 结果、日志和命令不交叉 |
| P-02 | 会话停止/恢复 | 发送 → 中止 → 重启应用 → 恢复 | 持久化消息不丢；不存在重复任务执行 |
| P-03 | 退出后子进程清理 | 枚举 SOXU 管理的完整进程树 | 正常退出后残留 0 个受管 Pi 进程 |
| P-04 | 长会话 | 预生成至少 50,000 条消息/事件、含长工具输出 | UI 不一次加载整个 JSONL；无持续无限增长缓存 |
| P-05 | 错误处理 | 模拟 429、网络断开、超时和 Pi RPC 异常 | 明确状态并可恢复；不触发无限付费重试 |
| P-06 | 跨平台 | Windows/macOS/Linux CI 或明确批准的试运行设备 | 各平台可启动并完成 Pi RPC 冒烟测试 |
| P-07 | 资源比较 | 同硬件、同 Pi 版本、同模型/扩展、同会话集，多次完整进程树采样 | 公布可复现数据；未达成目标不宣传节省比例 |
| P-08 | 安全门禁 | 未授权路径、文件操作和敏感信息注入测试 | 拦截越权，密钥不输出/提交 |

**性能预算待实测校准**：M1 建立可重复的空闲、2 Agent 活动、50k 事件长会话基线；M2 确定冷启动、内存峰值和响应延迟的正式阈值，跨平台分别记录。不能仅凭 Tauri 比 Electron 轻就宣称 SOXU 已达到特定节省比例。

## 5. 明确的非目标

- 不重做 Pi 模型路由、认证、工具、Skills、Extensions、JSONL 协议或 Agent 推理核心。
- 不把 PiDeck 作为 SOXU 产品运行时依赖；PiDeck **只监控开发阶段**。
- 不让 Agent 绕过审查、审批根目录依赖版本或擅自定稿 UI/UX。
- 不为炫技引入常驻后台进程、无边界内存缓存或未签名自动部署。

## 7. 已确认与待验证

- 已批准：主要依赖准确版本（Node >=24；本地 Node 26）、Rust Edition 2024、参考 ChatGPT 的对话优先 UI/UX、开发与审查均使用 `magpie / auto/deepseek-v4.1-flash`。
- **待验证**：Magpie 在 Pi 中可用性、实际额度与计费授权、pnpm/Cargo 锁文件生成、Windows/macOS/Linux 构建和完整回归。
- **仍需另外审批**：无人值守的付费预算上限、正式发行签名/公证凭据、对外发布渠道。
