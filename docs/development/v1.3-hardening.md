# SOXU v1.3 工程加固记录（版本号未锁定）

日期：2026-10-26。基于 v1.2 验证版增量修复；未变更 package.json / Cargo.toml / Tauri 依赖、产品版本号或正式 UI。

## 本轮变更

1. `guards.mjs`：在暂存代码前检查变更文件的体积及符号链接；拒绝符号链接、超限普通文件、超限二进制差异。Git `--numstat -z --no-renames` 对于二进制使用 `-`，现在按照实际文件大小计入预算，杜绝 NaN 绕过。
2. `review-invariants.mjs` / `worker.mjs`：断点恢复后执行 Commit、Push 或创建 PR，核验 HEAD 的直接父提交、提交信息和内容树是否与已测试且已审查的 tree 完全一致；不一致立即阻断并要求人工检查。
3. `process.mjs`：受管外部命令异常/中断时，优先等待子进程退出，再释放任务占用；给异常无法退出的进程设置有界终止兜底。
4. `rpc.mjs`：Pi 即使发出 `agent_settled`，也需等待实际 RPC 子进程退出才能启动下一质量检查；失败时延后至退出后再结束操作；加入强制终止兜底。
5. `tests/hardening.test.mjs`：新增二进制大小限制、符号链接阻断、提交身份验证、外部进程终止等待、Pi RPC 完成后等待退出五项独立回归测试。

## 进一步限制

- `maxChangedBytes` 的文本差异是按增删行数乘 10 的近似预算，而不是完整内容字节总量；二进制按实际当前文件大小计算。超限二进制文件删除本身不含新负载。生产级预算可再加强为 Git blob 实际尺寸累计。
- Windows 进程树实际回收仍需本机验证。超出强制退出兜底时返回超时，不应视为已确认全部后代退出。
- 无独立 OS 沙箱，任何 Agent 自动执行都需要低权限隔离环境。
