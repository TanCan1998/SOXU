# SOXU 开发路线图

> 本路线图表达**计划**，不是已经完成的工作。按 [`PRD`](../product/prd.md) 中的 P-01 至 P-08 验收。

- **M0 / 工程治理**：明确目标、双语 README、Agent 模型路由、配置和访问审计、进度监控设计、最小 CI、安全恢复。
- **M1 / 产品原型**：Tauri Rust-Vue 类型桥接、项目管理、Pi RPC 单会话、JSONL 读取索引、UI/UX 通过所有者审批后正式实施。
- **M2 / 多 Agent**：至少两个可同时运行的独立会话、生命周期管理、资源监测、超长时间线与异常恢复。
- **M3 / 开发工具**：Git Worktree、Diff/Checkpoint、PTY 终端、Skills/Extensions 展示与交互。
- **M4 / 发布**：完整跨平台打包、签名/公证、稳定性及性能回归、受控 prerelease。

任务进展以 GitHub Issue/PR/Actions 为准，本地检查点用于补充诊断；状态不得根据模型的自然语言自报“完成”来判定。
