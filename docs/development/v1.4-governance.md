# SOXU v1.4 工程治理与双语文档验收记录

> 2026-10-26 · 引导工程迭代，**不等于正式 SOXU 产品版本**。本轮没有锁定 pnpm、Rust、Tauri、Vue、Vite 等仍待审批的依赖，也没有把 UI 原型当作正式 UI/UX。

## 基于 v1.3 的变更

1. `README.md` 改为中文完整入口，新增 `README.en.md` 英文完整入口，说明新项目状态、启动/监控流程、模型路由、风险和审批边界。
2. `docs/product/prd.md` 与 `docs/development/roadmap.md`：明确定义 M0～M4、MVP 范围/非目标、P-01～P-08 可验证验收指标。全部是**目标**，未经 Windows/跨平台测量不得标记通过。
3. `automation/agent-models.json` 和 `automation/loop/src/agent-models.mjs`：Developer/Reviewer 可使用不同 Pi Provider/Model/Thinking，支持 PowerShell `SOXU_{DEVELOPER|REVIEWER}_{PROVIDER|MODEL|THINKING}` 环境变量临时覆盖；缺省继承 Pi 设置。
4. `automation/loop/src/rpc.mjs`、`worker.mjs`：将具体选择转换为 Pi CLI RPC `--provider`/`--model`/`--thinking` 参数，严格限制字符集合避免 Shell 拼接注入。
5. 新增 `pnpm agent:models` 零付费调用的本地配置预览，`pnpm agent:doctor` 会列出角色路由；仅显示公开 ID，不显示密钥。
6. 新增模型、安全、观测、测试与 DoD 规范；保护 `automation/agent-models.json` 不被 Developer 自行修改。
7. Node 最低要求更新为 `>=24`，CI Node 改为 24；保留 pnpm 等尚待批准的旧原型声明（不隐性升级）。
