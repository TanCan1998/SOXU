## 需要在你的 Windows 环境完成的检查

```powershell
cd D:\Projects\SOXU
node -v
pnpm -v
rustc --version
pi --list-models
pnpm install --lockfile-only
cargo generate-lockfile
pnpm install --frozen-lockfile
node ../soxu-agent-loop/automation/loop/src/cli.mjs models
node ../soxu-agent-loop/automation/loop/src/cli.mjs status
pnpm check
cargo fmt --all -- --check
cargo test --workspace --locked
cargo check --workspace --locked
pnpm tauri:dev
```

在确认实际安装、认证与额度后，才执行 `node ../soxu-agent-loop/automation/loop/src/cli.mjs start -- --dry-run` 与经过授权的开发任务。**别在 `pnpm-lock.yaml`、`Cargo.lock` 缺失时直接推送并要求冻结锁文件 CI 通过。**
